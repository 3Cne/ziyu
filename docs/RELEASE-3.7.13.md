## 新增

### 统一材质系统
- 新增 `Material.kt`，用 `SurfaceRole` 统一栏、卡片、弹窗、控件、纸面。
- 每个主题可以独立保存一套材质参数，未设置的值继承公共默认值。
- 设置里新增分角色材质页，可分别调填充、模糊、边缘、折射、颗粒、流光等。
- 材质边框统一为纯色，不做渐变高光：
  - 栏 / 卡片 / 弹窗：`8dp`
  - 控件：`2.5dp`
  - 颜色：亮色向 ink 偏 8%，暗色向白偏 8%
- 书籍封面也加边框：大封面 8dp，中封面 3dp，小封面 2dp，颜色取主题纸色的 8% 偏移。

### 纸张系统
- 空白、虚线、实线、稿纸四种纸面。
- 注意/书籍编辑器右上角三点菜单可直接切换纸面、调线条深浅。
- 纸面线由 Compose 单独绘制，固定网格循环，随正文滚动，不依赖文字行是否存在。
- 行高变化时重新计算网格。

### 提醒
- 正文内待办可以直接加提醒，不再跳到独立页面。
- 提醒行跟随待办段落，不能被待办末尾回车隔开。
- 点提醒行编辑；点提醒下方空白处新增可写行。
- 提醒会请求通知权限，并在设置里可以进入系统提醒设置。
- 通知标题改为具体的待办文字，正文显示笔记标题，点击通知回到对应笔记。

### 新手引导
- 恢复并重做 8 页引导：
  - 本地写作
  - 光标与草稿
  - 正文内待办
  - 自定义提醒
  - 纸张与材质
  - 导出与备份
  - 主题与界面
  - 本地数据
- 新增品牌头、步骤计数、特性标签、进度条和“开始写”按钮。
- 设置 → 关于 → 重看功能引导，可随时重看。

## 改进

- 新建/编辑书籍表单的字段切换保留 `AnimatedPane` 滑动和淡入动画。
- Dialog 窗口请求更高刷新率，改善表单进入时的窗口帧率。
- 编辑器纸面线、行距、滚动位置联动。
- 顶部/底部材质统一到同一渲染器，减少各页面各写一套透明度。
- 旧版已保存的材质参数做一次性迁移，保留用户调过的颜色/模糊，只修正边框宽度。

## 修复

- Toast 未避让输入法，键盘打开时会被挡住；统一 `ToastLayer` 增加 IME 避让。
- 提醒时间行参与首行缩进、光标可进入；现在提醒行不缩进，光标统一弹回待办末尾。
- 待办行被首行缩进推到第二行；现在待办标记固定在行首，当前行有正文时另起无缩进行。
- 新建书籍点蒙版会关闭；现在只有 X/取消/系统返回关闭。

- 待办和提醒被换行拆开的问题。
- 提醒行下方无法继续书写的问题。
- 新提醒流程没有请求通知权限，导致到点没有通知。
- 通知标题固定为“该写一点了”，看不到具体待办。
- 书籍封面没有边框、和卡片材质不统一。
- 旧版新手引导入口和引导数据字段丢失。
